# 보안사고 신고 및 대응 절차

문서번호 SEC-PRC-003 · 시행 2025년 9월 1일 · 개정 2026년 4월 1일 · 소관 정보보호팀

## 1. 보안사고란?
아래와 같은 상황은 모두 보안사고이며, 사소해 보여도 반드시 신고해야 합니다. 신고한 직원에게는 어떠한 불이익도 주지 않습니다.

- 피싱 메일의 링크를 클릭했거나 첨부파일을 열었을 때
- 계정 정보(비밀번호, MFA 승인)를 타인에게 알려 주었거나 본인이 하지 않은 로그인 알림을 받았을 때
- 노트북, 휴대폰, 사원증 등 회사 자산이나 출입 수단을 분실·도난당했을 때
- 개인정보나 대외비 자료가 외부로 잘못 발송되었을 때
- PC에서 랜섬웨어, 악성코드 감염이 의심될 때

## 3. 신고 기한

| 사고 유형 | 1차 신고 기한 |
|---|---|
| 피싱 메일 클릭, 악성코드 감염 의심 | 인지 후 즉시 (30분 이내) |
| 계정 탈취 의심 | 인지 후 즉시 (30분 이내) |
| 개인정보·대외비 자료 오발송 및 유출 의심 | 인지 후 30분 이내 |
| 장비·사원증 분실 및 도난 | 인지 후 1시간 이내 |

1차 신고는 전화나 메시지로 간단히 하면 됩니다. 1차 신고 후 24시간 이내에 한빛워크 [보안] > [보안사고 보고서]를 작성하여 제출합니다.

## 4. 신고 후 초동 조치
1. 악성코드 감염이 의심되면 노트북의 네트워크(Wi-Fi, 유선 랜)를 즉시 끊습니다. 전원은 끄지 마세요. 메모리 분석이 필요할 수 있습니다.
2. 계정 탈취가 의심되면 정보보호팀 안내에 따라 비밀번호를 변경하고 MFA 기기를 재등록합니다.
3. 메일을 잘못 보낸 경우 Outlook의 '메일 회수'를 시도하고, 수신자에게 삭제를 요청한 뒤 그 내용을 정보보호팀에 알립니다.
4. 피싱 메일은 다른 사람에게 전달하지 말고 Outlook의 '피싱 신고' 버튼만 누릅니다.

## 5. 사고 등급
정보보호팀은 접수한 사고를 조사하여 다음과 같이 등급을 판정합니다. 보안사고 등급(S1~S3)은 서비스 장애 등급(P1~P4)과 별개입니다.

| 등급 | 기준 | 보고 |
|---|---|---|
| S1 | 개인정보 유출 확인, 서비스 침해, 랜섬웨어 확산 | 2시간 이내 대표이사 보고 |
| S2 | 단일 PC 감염, 계정 탈취, 대외비 자료 유출 의심 | 당일 CTO·CPO 보고 |
| S3 | 피싱 클릭 후 피해 없음, 분실 장비 원격 삭제 완료 | 주간 보안 리포트에 포함 |

## 6. 사후 관리
- S1, S2 사고는 정보보호팀이 사고 종료 후 10영업일 이내에 원인 분석 보고서와 재발 방지 대책을 작성합니다.
- 사고와 관련된 직원은 필요한 경우 보안 재교육(1시간)을 이수합니다.
- 개인정보 유출 사고의 대외 신고와 통지는 「개인정보 처리 지침」 7장에 따릅니다.
