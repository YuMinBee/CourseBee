# 한빛워크(HanbitWork) 사용자 매뉴얼

적용 버전: v3.4 · 작성: IT지원팀 · 2026년 7월 10일

한빛워크는 근태, 휴가, 전자결재, 경비, 예약, 자산, 권한 신청을 한곳에서 처리하는 사내 업무 포털입니다.

## 1. 접속 방법
- PC: 크롬 또는 엣지 브라우저에서 https://work.hanbit.internal 접속 (사내망 또는 VPN 연결 필요)
- 모바일: '한빛워크' 앱 설치. 개인 휴대폰은 MDM 앱을 먼저 설치해야 로그인할 수 있습니다.
- 로그인: SSO 계정으로 로그인하며, 로그인할 때마다 MFA(Okta Verify) 승인이 필요합니다.
- 로그인 상태는 PC에서 8시간, 모바일 앱에서 7일간 유지됩니다.

## 2. 메뉴 구성

| 메뉴 | 주요 기능 |
|---|---|
| 근태 | 출퇴근 기록, 재택 출근·퇴근, 근무 유형 설정, 근태 정정 신청 |
| 휴가 | 휴가 신청·취소, 잔여 연차 조회 |
| 근무 일정 | 재택근무·외근 일정 등록 |
| 결재 | 결재함, 결재 위임, 문서 회수 |
| 경비 | 법인카드 내역, 개인 경비 청구, 출장 신청·정산 |
| 구매 | 구매 요청, 검수 완료 |
| 예약 | 회의실, 방문객 등록, 정기주차 신청, 시간 외 출입 신청 |
| 자산 | 내 자산, 자산 반출 신청 |
| 권한 | 권한 신청, 내 권한 조회 |
| 보안 | 보안사고 보고서 |

## 3. 휴가 신청하기
1. [휴가] > [휴가 신청]을 누릅니다.
2. 휴가 종류(연차, 반차, 반반차, 경조, 병가, 건강검진 등)를 고릅니다.
3. 날짜와 시간을 선택합니다. 반차는 오전·오후, 반반차는 출근 직후 2시간 또는 퇴근 직전 2시간 중에서 고릅니다.
4. 사유를 입력합니다. 경조휴가는 증빙 파일을 첨부합니다.
5. 결재선을 확인합니다. 팀장이 자동으로 지정되며, 5일 이상 연속 휴가는 본부장이 자동으로 추가됩니다.
6. [상신]을 누르면 신청이 완료됩니다.

- 신청 기한이 지난 날짜를 고르면 '신청 기한 경과' 경고가 뜨고 상신 버튼이 비활성화됩니다. 이때는 팀장에게 연락한 뒤 [사후 신청] 버튼을 이용합니다.
- 잔여 연차는 [휴가] > [내 휴가 현황]에서 확인할 수 있습니다. 이월 연차는 별도 줄에 소멸 예정일과 함께 표시됩니다.

## 4. 휴가 취소하기
- 승인 전 휴가는 [휴가] > [신청 내역]에서 바로 취소할 수 있습니다.
- 승인된 휴가는 사용일 전날까지 [취소]를 누르면 팀장에게 취소 알림이 가고 즉시 취소됩니다.
- 사용일 당일이나 이미 지난 휴가는 [취소 요청]으로 팀장 승인을 받아야 취소됩니다.

## 5. 전자결재
- 결재 문서는 [결재] > [결재함]에서 확인합니다. 결재 요청이 오면 Slack 한빛워크 봇이 알림을 보냅니다.
- 상신한 문서는 첫 번째 결재자가 승인하기 전까지 [회수]할 수 있습니다.
- 출장·휴가 등으로 결재가 어려우면 [결재] > [위임 설정]에서 최대 30일 동안 다른 사람에게 결재를 위임할 수 있습니다. 위임받는 사람은 같은 직급 이상이어야 합니다.

## 6. 회의실 예약하기
1. [예약] > [회의실]을 누릅니다.
2. 층과 날짜를 선택하면 회의실별 예약 현황이 시간표로 표시됩니다.
3. 원하는 시간대를 드래그해 선택합니다. (1회 최대 2시간)
4. 회의 제목을 입력하고 참석자를 추가합니다. 참석자에게는 Outlook 일정 초대가 자동으로 발송됩니다.
5. [예약]을 누릅니다. 9층 '누리'는 총무팀 승인 후 확정됩니다.

## 7. 경비 정산하기
1. [경비] > [법인카드 내역]에서 정산할 결제 건을 선택합니다.
2. 계정과목을 고르고 사용 목적과 참석자를 입력합니다.
3. 영수증 사진을 첨부합니다. 모바일 앱에서는 카메라로 바로 촬영할 수 있습니다.
4. [상신]을 누릅니다.

## 8. 출장 신청과 정산
1. 출발 전에 [경비] > [출장 신청]에서 출장지, 기간, 목적, 예상 경비를 입력하고 상신합니다. 해외 출장은 본부장이 결재선에 자동으로 추가됩니다.
2. 출장 중 법인카드로 결제한 내역은 출장 기간과 자동으로 연결됩니다.
3. 복귀 후 [경비] > [출장 정산]을 열면 출장 신청 정보와 카드 내역이 미리 채워져 있습니다. 개인카드로 결제한 비용과 영수증을 추가하고 상신합니다.
4. 해외 출장의 일비는 출장 지역과 일수에 따라 자동 계산되며, 직접 수정할 수 없습니다.

## 9. 근태 정정 신청
- 사원증 태깅을 잊었거나 기록이 잘못된 경우 [근태] > [근태 정정 신청]에서 날짜를 고르고 실제 출근·퇴근 시각과 사유를 입력합니다.
- 정정 신청은 팀장이 승인하면 반영됩니다. 월간 근태가 마감된 뒤에는 정정 메뉴가 잠깁니다.

## 10. 권한 신청
1. [권한] > [권한 신청]에서 시스템 이름을 검색합니다.
2. 필요한 권한 등급(읽기, 쓰기, 관리자)과 사용 기간, 사유를 입력합니다.
3. 결재선은 시스템별로 자동 지정됩니다. 운영 환경 권한은 팀장과 SRE팀장, 개인정보 시스템 권한은 팀장과 정보보호팀이 승인합니다.
4. 승인되면 보통 1시간 안에 권한이 자동으로 부여되고, 만료 7일 전에 알림을 받습니다.

## 11. 알림 설정
[내 정보] > [알림 설정]에서 결재 요청, 휴가 승인, 권한 만료 등의 알림을 Slack, 메일, 앱 푸시 중 어디로 받을지 선택할 수 있습니다. 결재 요청 알림은 끌 수 없습니다.

## 12. 모바일 앱에서 할 수 있는 일
| 기능 | PC | 모바일 앱 |
|---|---|---|
| 휴가 신청·취소 | 가능 | 가능 |
| 결재 승인·반려 | 가능 | 가능 |
| 출퇴근 기록 | 가능 | 사내 Wi-Fi 연결 시에만 가능 |
| 재택 출근·퇴근 | 가능 | 가능 |
| 법인카드 정산 | 가능 | 가능 (영수증 촬영) |

- 모바일 앱은 iOS 16 이상, Android 12 이상에서 동작합니다.
- 휴대폰을 잃어버리면 정보보호팀 핫라인으로 신고하세요. MDM으로 업무 앱 데이터가 원격 삭제됩니다.

## 13. 문제 해결
- 화면이 하얗게 나오거나 메뉴가 보이지 않으면 브라우저 캐시를 지운 뒤 다시 접속합니다.
- 사파리 브라우저에서는 결재선 편집 화면의 드래그 기능이 동작하지 않습니다. 크롬이나 엣지를 사용하세요.
- 그 밖의 오류는 화면 캡처와 함께 #it-helpdesk에 문의합니다.
