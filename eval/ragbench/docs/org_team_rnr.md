# 조직도 및 팀별 역할과 책임(R&R)

기준일: 2026년 7월 1일 (2026년 하반기 조직 개편 반영) · 관리: 인사팀

## 1. 회사 개요
- 회사명: 주식회사 한빛데이터 (Hanbit Data Inc.)
- 설립: 2014년
- 임직원: 약 430명 (2026년 6월 말 기준)
- 주요 서비스: 기업용 데이터 통합·분석 SaaS '데이터허브(DataHub)'
- 근무지: 판교 본사(한빛타워 7~11층), 부산 R&D센터(해운대구 센텀)

## 2. 경영진
- 대표이사(CEO): 정민호
- 최고기술책임자(CTO): 한서진 — 기술본부장 겸임
- 최고재무책임자(CFO): 오유진 — 경영지원본부장 겸임
- 제품본부장: 문지원
- 사업본부장: 배상훈

- PM팀: 제품 로드맵, 요구사항 정의, 릴리스 노트 작성
- 디자인팀: UX 리서치, 제품 디자인

- CS팀: 고객 문의 대응, 장애 시 고객 공지(상태 페이지), 고객 교육

## 4. 2026년 7월 조직 개편 주요 내용
- IT지원팀이 기술본부에서 경영지원본부로 이동했습니다. 헬프데스크 채널과 내선 번호는 바뀌지 않았습니다.
- 데이터엔진팀에 부산 R&D센터 인력이 통합되었습니다.
- 정보보호팀장이 개인정보 보호책임자(CPO)를 겸임합니다.
