# 개인정보 처리 지침

- 문서번호: SEC-GUD-002
- 버전: v1.4
- 최종 개정: 2026년 5월 20일
- 개인정보 보호책임자(CPO): 박정훈 (정보보호팀장)

## 1. 기본 원칙
회사는 데이터허브(DataHub) 서비스 운영 과정에서 고객사 담당자와 최종 이용자의 개인정보를 처리한다. 모든 임직원은 업무 수행에 필요한 최소한의 개인정보만 처리하며, 목적 외 이용과 제3자 제공을 금지한다.

## 2. 개인정보 접근 권한
1. 운영 데이터베이스와 고객 관리 시스템(CRM)의 개인정보 접근 권한은 한빛워크 [권한 신청]으로 요청한다.
2. 권한은 팀장 승인과 정보보호팀 승인을 모두 받아야 부여된다.
3. 개인정보 접근 권한의 유효기간은 90일이며, 계속 필요한 경우 만료 전에 다시 신청한다.
4. 부서 이동이나 퇴사 시 기존 권한은 즉시 회수된다.
5. 모든 개인정보 조회 기록은 접속기록 관리 시스템에 2년간 보관되며, 정보보호팀이 매월 점검한다.

## 3. 개인정보 다운로드 및 반출
- 개인정보가 포함된 데이터는 원칙적으로 내려받지 않는다.
- 업무상 불가피하게 내려받아야 하는 경우 아래 기준에 따라 마스킹한 뒤, 다운로드 사유를 시스템에 기록한다.
- 1,000건 이상의 개인정보를 내려받거나 외부로 전달하는 경우에는 CPO의 사전 승인을 받아야 한다.
- 내려받은 파일은 업무 종료 후 즉시 삭제하며, 개인 클라우드나 개인 메일로 전송하지 않는다.

## 4. 마스킹 기준

| 항목 | 마스킹 방법 | 예시 |
|---|---|---|
| 이름 | 가운데 글자 마스킹 | 홍*동 |
| 휴대전화번호 | 가운데 4자리 마스킹 | 010-****-5678 |
| 이메일 | 아이디 앞 2자리 외 마스킹 | ha***@example.com |
| 주소 | 시·군·구까지만 표시 | 경기도 성남시 분당구 *** |
| 생년월일 | 연도만 표시 | 1990-**-** |

주민등록번호는 법령에 근거가 있는 경우를 제외하고 수집하지 않는다.

## 5. 개발·테스트 환경
- 개발 및 테스트 환경에서는 실제 개인정보를 사용하지 않는다.
- 테스트 데이터가 필요하면 데이터엔진팀이 제공하는 가명처리 데이터셋(매주 월요일 갱신)을 사용한다.
- 장애 분석을 위해 운영 데이터를 복제해야 하는 경우 정보보호팀 승인을 받고, 분석 종료 후 7일 이내에 파기한다.

## 6. 보관 및 파기
- 서비스 탈퇴 회원의 개인정보는 탈퇴일로부터 30일 이내에 파기한다.
- 다만 관계 법령에 따라 보관이 필요한 정보(계약·청약철회 기록 5년, 소비자 불만 처리 기록 3년, 접속 로그 3개월)는 해당 기간 동안 분리 보관한다.
- 종이 문서는 보안 파쇄함을 이용하고, 저장매체는 IT지원팀을 통해 물리적으로 파기한다.

## 7. 개인정보 유출 대응
1. 개인정보 유출이 의심되면 즉시 정보보호팀에 신고한다. 신고 방법은 「보안사고 신고 및 대응 절차」를 따른다.
2. 정보보호팀은 유출 사실을 확인한 때부터 72시간 이내에 개인정보보호위원회에 신고하고 정보주체에게 통지한다.
3. 유출 원인 분석과 재발 방지 대책은 CPO가 대표이사에게 보고한다.

## 8. 교육
모든 임직원은 연 1회 개인정보보호 교육을 이수하여야 하며, 개인정보 접근 권한을 가진 직원은 추가로 반기 1회 심화 교육을 받는다.
