# 포스트모템: 2026-06-12 데이터허브 API 전면 장애 (P1)

- 작성: SRE팀 김도윤, 플랫폼팀 이서연
- 리뷰 회의: 2026년 6월 18일(목)
- 상태: 액션 아이템 진행 중

## 요약
2026년 6월 12일(금) 오전 9시 7분부터 9시 54분까지 47분 동안 데이터허브 API 요청의 상당수가 실패했다. 전체 고객사의 약 64%가 대시보드 조회와 API 호출에서 오류를 겪었다. 원인은 전날 배포된 v4.9.0의 신규 기능이 DB 커넥션을 반환하지 않는 경로를 포함하고 있었고, 오전 9시 일일 집계 배치가 시작되면서 요청이 몰려 커넥션 풀(최대 200개)이 고갈된 것이다. v4.8.2로 롤백하여 복구했다.

## 근본 원인
v4.9.0에서 추가된 '대시보드 공유 링크' 기능은 예외가 발생할 때 트랜잭션을 종료하지 않아 DB 커넥션을 반환하지 않았다. 평소 트래픽에서는 누수 속도가 느려 드러나지 않았지만, 배치 작업으로 동시 요청이 3배 가까이 늘자 수 분 만에 커넥션 풀이 바닥났다.

카나리 단계에서 문제를 잡지 못한 이유는 다음과 같다.
- 카나리 트래픽(5%, 25%)이 적어 누수가 임계점에 이르지 않았다.
- 단계별 관찰 시간이 10분으로 짧았다.
- DB 커넥션 사용률이 카나리 분석 지표에 포함되어 있지 않았고, 이를 감시하는 알람도 없었다.

## 잘한 점
- 1차 on-call이 호출 4분 만에 확인하여 P1 최초 응답 목표(15분)를 지켰다.
- 원인이 확정되기 전에 롤백을 결정하여 복구 시간을 줄였다.

## 개선할 점
- 상태 페이지 공지가 P1 선언 후 34분 만에 올라가 목표(30분)를 넘겼다.
- 롤백 결정까지 37분이 걸렸다. 최근 배포가 있었다면 더 일찍 롤백을 검토했어야 한다.
