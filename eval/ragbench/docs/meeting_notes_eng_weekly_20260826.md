# 엔지니어링 주간 회의록 — 2026년 8월 26일(수)

- 시간/장소: 10:00~11:00, 7층 백두 + Zoom
- 참석: 한서진(CTO), 김도윤(SRE), 이서연(플랫폼), 송태경(데이터엔진), 김예린(프론트엔드), 장하람(QA)
- 작성: 김도윤

## 1. 지난주 액션 아이템 점검
- 6/12 장애 포스트모템 액션 아이템 5건 중 4건 완료. 남은 1건(DB 커넥션 풀 알람 추가)은 9월 첫째 주 완료 예정.
- review-roulette 봇 재배정 기능 배포 완료.

## 2. API p95 응답시간 알람 기준 변경 (결정)
- 현황: p95 Warning(800ms) 알람이 8월에만 214건 발생, 그중 약 70%가 대시보드 대용량 조회로 인한 일시적 지연으로 오탐에 가까움.
- 결정: 2026년 9월 1일부터 API p95 응답시간 Warning 기준을 800ms에서 1,000ms로 올린다. 지속 시간 조건(10분)은 그대로 유지한다.
- Critical 기준(2,000ms 이상 5분 지속)은 변경하지 않는다.
- 담당: 김도윤 — alert-rules 저장소 PR 및 「모니터링 및 알람 기준」 문서 갱신

## 3. 추석 연휴 배포 동결
- 동결 기간: 2026년 9월 22일(화) 18:00 ~ 9월 29일(화) 10:00
- 동결 기간의 마지막 정기 배포는 9월 22일(화) 오후 배포. 연휴 후 첫 정기 배포는 10월 1일(목).
- 동결 기간 중 긴급 핫픽스는 기존 규정대로 CTO 승인 필요.
- 연휴 기간 on-call은 평소대로 운영하며, 대기 수당은 공휴일 기준으로 지급.

## 4. 코드 리뷰 응답 시간
- 8월 첫 리뷰 1영업일 이내 응답률 62%로 목표(90%) 미달.
- 리뷰 요청 후 4시간이 지나면 review-roulette이 리뷰어에게 Slack 리마인드를 보내도록 설정하기로 함.
- 대형 PR(1,000줄 이상) 비율이 18%. 각 팀장은 PR 분할을 독려하기로 함.

## 5. on-call 수당 인상 건
- 플랫폼팀에서 주말 대기 수당 현실화 요청.
- 인사팀과 협의 중이며 이번 회의에서는 결정하지 않음. 다음 달 회의에서 인사팀 의견을 공유하기로 함.

## 6. 기타
